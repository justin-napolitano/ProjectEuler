This repo has Python solutions for various Project Euler problems. Each script implements algorithms to efficiently solve specific mathematical challenges.

## Key Features
- Solutions for multiple Project Euler problems.
- Focus on algorithmic accuracy and clarity.
- Topics include palindromes, Fibonacci sequences, prime factorization, and multiples.

## Tech Stack
- Python 3

## Getting Started

### Prerequisites
- Ensure Python 3.x is installed.

### Installation
Clone the repo and navigate to the directory:

```bash
git clone https://github.com/justin-napolitano/ProjectEuler.git
cd ProjectEuler
```

### Running Solutions
Go to the `euler_python_solutions` folder and execute a script:

```bash
cd euler_python_solutions
python Problem1.py
```

### Gotchas
- Fix `Proboem3.py` typo—it's a duplicate of `Problem3.py`.
- Some scripts are incomplete; see `Problem2.py` for example. 

That's it! Dive in and start solving problems.
